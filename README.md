🎓 CampusFlow

CampusFlow is a web-based academic management platform designed to bring faculty and students together in one centralized workspace. It simplifies academic administration by allowing faculty to manage student records, publish assignments, track academic performance, and respond to student queries.

Students can access their personal dashboards to view marks, check assignments, manage their profiles, and communicate directly with faculty.

The platform provides a simple, organized, and user-friendly academic experience for both faculty and students.

✨ Features
👨‍🏫 Faculty Portal

- Faculty Authentication – Create an account and securely sign in using name, email, employee ID, and password.
- Dashboard Overview – View total students, published assignments, open queries, and average academic scores.
- Student Management – Add, edit, delete, and search student records using names or roll numbers.
- Automatic Student Login – Generate a unique portal login name for each registered student.
- Assignment Management – Create, edit, publish, and delete assignments with descriptions and due dates.
- Mark Management – Record subject-wise student marks with maximum score details.
- Performance Analysis – Visualize class performance through charts and organized result tables.
- Query Management – View student questions and send or update responses.

👨‍🎓 Student Portal

- Student Login – Sign in using the registered portal login name and date of birth.
- Personal Dashboard – View overall scores, assignment count, query count, and roll number.
- My Profile – Access personal and academic information registered by faculty.
- My Scores – View subject-wise marks, percentages, and last-updated dates.
- Assignments – Check coursework details, subjects, descriptions, due dates, and faculty names.
- Ask Faculty – Submit academic questions and track faculty responses.

 📖 How to Use

 Faculty Workflow

1. Open the CampusFlow landing page.
2. Select Faculty Sign In
3. Create a faculty account or sign in.
4. Navigate to the Students section and register student details.
5. Manage assignments and publish coursework.
6. Enter student marks and monitor academic performance.
7. Open the Queries section to view and respond to student questions.

Student Workflow

1. Open the Student Portal.
2. Enter the generated portal login name and registered date of birth.
3. Access the personal dashboard.
4. View profile information and academic scores.
5. Check published assignments and due dates.
6. Submit questions through Ask Faculty.
7. Track faculty responses.
